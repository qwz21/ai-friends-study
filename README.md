# 친구와 이야기해요 — 설치 안내

1학년이 세 "친구"(가·나·다)를 체험하고, 각 친구가 인공지능인지 판단하며 그 이유를 말하는 조사용 웹앱입니다.
응답은 구글 시트에 저장되고, 녹음 파일은 구글 드라이브에 저장됩니다.

```
web/            ← 태블릿에서 여는 화면 (인터넷 주소에 올림)
  config.js     ← 서버 주소, 대기 시간 설정
  content.js    ← 질문 문항, 나 친구 대화 갈래  ★ 문항 수정은 여기서
  app.js, style.css, index.html
apps-script/
  Code.gs       ← 구글 시트에 붙이는 저장 서버 + 다 친구(Claude) 연결
```

## 0. 지금 바로 연습해 보기 (설치 없이)
`config.js`의 `API_URL`이 비어 있으면 **연습 모드**입니다. 시트로 보내지 않고, 다 친구는 가짜 대답을 합니다.
```
cd ~/Documents/ai-friends-study/web && python3 -m http.server 8000
```
→ 맥의 크롬에서 http://localhost:8000 열기

## 1. 구글 시트 + 저장 서버 (10분)
1. 구글 드라이브에서 새 스프레드시트 만들기 (예: `친구와이야기해요_응답`)
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본 `Code.gs` 내용을 모두 지우고 `apps-script/Code.gs` 내용을 붙여넣기 → 저장
4. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 추가**
   - `ANTHROPIC_API_KEY` = Claude API 키 (console.anthropic.com에서 발급)
   - (선택) `APP_TOKEN` = 아무 문자열 (config.js에도 같은 값)
5. 편집기 위쪽 함수 목록에서 **`setup` 선택 → 실행** → 권한 승인
   (“확인되지 않은 앱” 경고가 나오면 고급 → 이동. 본인이 만든 스크립트라 괜찮습니다)
6. **`testChat` 실행** → 실행 로그에 다 친구 인사가 찍히면 API 연결 성공
7. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 나오는 URL(`.../exec`) 복사
8. `web/config.js`의 `API_URL`에 붙여넣기

> Code.gs를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 2. 화면 주소 (GitHub Pages)
- 주소: **https://qwz21.github.io/ai-friends-study/**
- 저장소: https://github.com/qwz21/ai-friends-study (공개 — 응답·녹음·API 키는 여기에 올라가지 않음)
- 업데이트: 파일을 고치고 커밋·푸시하면 1~2분 뒤 같은 주소에 반영됩니다. 패드에서는 새로고침.
- 고칠 때마다 `config.js`의 `APP_VERSION`을 올려 주세요 (시트에 함께 기록됨).

## 3. 갤럭시 패드 준비 (조사 전날)
1. 크롬으로 주소 열기 → 메뉴 → **홈 화면에 추가**
2. 처음 화면의 **🔊 목소리 확인** → 한국어 목소리가 나오는지
3. 학생 ID에 `테스트` 입력 → 사전 조사에서 녹음 한 번 → **마이크 허용** 누르기
4. 시트에 `테스트` 줄이 생겼는지, 드라이브 `친구와이야기해요_녹음` 폴더에 파일이 생겼는지 확인 후 테스트 줄 삭제
5. 화면 자동 꺼짐 시간 늘리기, 방해 금지 모드, 소리 크기 확인

## 시트에 쌓이는 내용
| 탭 | 한 줄 = | 주요 열 |
|---|---|---|
| 사전조사 | 학생 1명 | 학년, 성별, 경험_5개, 인공지능_들어봄, 어디서/뜻(교사기록·녹음) |
| 세션1~3 | 학생 1명 × 세션 | 판단, 이유_교사기록, 이유_녹음, 연구자메모, 체험시간, 대화기록, 실제_처리시간 |

- **대화기록**: `[초] 아이/친구: 내용` — 아이가 "같은 말만 해요"라고 할 때 실제 대화와 대조할 수 있습니다.
- **실제_처리시간_최대ms**: 다 친구가 설정 대기 시간(기본 3초)보다 오래 걸린 적이 있는지 확인용. 넘는 일이 잦으면 `RESPONSE_DELAY_MS`를 늘리세요.
- 인터넷이 끊겨 저장이 실패하면 기기에 보관되고, 처음 화면의 **미전송 n건 다시 보내기**로 보낼 수 있습니다. **이 기기 백업 내려받기**로 전체 기록을 파일로 받을 수도 있습니다.

## 연구 설계 메모
- 세 친구는 같은 화면 구성·같은 목소리(같은 기기)·같은 대기 시간을 쓰고, 색만 다릅니다(가 노랑, 나 초록, 다 분홍 — content.js에서 변경). 화면에 "인공지능", "AI"라는 말은 판단 질문에만 나옵니다.
- 다 친구의 지시문(말투, 정체 숨기기, 안전 규칙)은 `Code.gs`의 `SYSTEM_PROMPT`에 있습니다.
- 녹음은 아이 음성(개인정보)이므로 동의서·IRB 서류에 수집·보관·파기 계획을 적어 주세요. 녹음 폴더는 공유하지 마세요.
- 다 친구는 Claude API 사용료가 듭니다(claude-sonnet-5 기준 대답 한 번에 약 5~8원, 학생 30명 전체 약 2,000원 정도로 예상. 실제 금액은 console.anthropic.com에서 확인). 키는 시트 스크립트 속성에만 두고 웹 화면 파일에는 넣지 마세요.
